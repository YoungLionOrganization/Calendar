# YoungLion Calendar

[![Qt 6.8+](https://img.shields.io/badge/Qt-6.8%2B-41cd52)](https://www.qt.io/)
[![Linux CI](https://github.com/YoungLionOrganization/Calendar/actions/workflows/linux.yml/badge.svg?branch=main)](https://github.com/YoungLionOrganization/Calendar/actions/workflows/linux.yml)
[![License](https://img.shields.io/badge/License-GPLv3-blue)](COPYING)

YoungLion Calendar is an offline personal calendar for Linux and Android. It provides year, month, week, and agenda views, recurring events, reminders, and iCalendar import and export. The interface is available in English, Turkish, and Azerbaijani.
