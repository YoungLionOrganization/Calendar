YoungLion Calendar’s first GitHub release supports year, month, week, and agenda views on phones, tablets, and desktop screens.

- Month view prepares the previous, current, and next years in the background.
- Qt SQL and SQLite store events. The first launch migrates existing events and reads existing preferences.
- Import and export iCalendar files. Local calendars support colors, recurring events, and reminders.

## Downloads

- Native package for **Arch Linux x86_64**.
- Test-signed APK for **Android arm64**.
- Source archive and **SHA256SUMS** for download verification.

The build and startup checks covered Arch-based Linux and Alpine. Source recipes are included for Flatpak, Debian, Ubuntu, and Fedora. At the time of release, installation checks for those recipes and Android device-level integration checks were pending. GNOME Evolution Data Server and KDE Akonadi connectors are unavailable in this version.
